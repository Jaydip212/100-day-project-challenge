# E-learning Platform Frontend

A modern and responsive E-learning platform frontend built with HTML, CSS, JavaScript, Bootstrap, and Tailwind CSS.

## Features

- Responsive design that works on all devices
- Modern UI with smooth animations
- Course catalog with featured courses
- Newsletter subscription
- Smooth scrolling navigation
- Interactive course cards
- Features section
- Mobile-friendly navigation

## Project Structure

```
.
├── index.html          # Main HTML file
├── css/
│   └── style.css      # Custom CSS styles
├── js/
│   └── script.js      # Custom JavaScript functionality
└── README.md          # Project documentation
```

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5.3.0
- Tailwind CSS
- Font Awesome Icons

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start exploring the E-learning platform!

## Features Implemented

- Responsive navigation menu
- Hero section with call-to-action
- Featured courses section with hover effects
- Why Choose Us section with icons
- Newsletter subscription form
- Social media links
- Smooth scrolling
- Animations on scroll
- Course enrollment interaction (demo)
