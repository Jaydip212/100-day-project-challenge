# Online Code Editor

A simple online code editor built with HTML, CSS, JavaScript, and Tailwind CSS. This editor allows you to write and preview HTML, CSS, and JavaScript code in real-time.

## Features

- Three-language support (HTML, CSS, JavaScript)
- Live preview
- Clean and modern UI using Tailwind CSS
- Syntax highlighting
- Responsive design
- Real-time code execution
- Easy-to-use interface

## How to Use

1. Open `index.html` in your web browser
2. Select the language tab you want to work with (HTML, CSS, or JS)
3. Write your code in the editor
4. Click the "Run" button to see the output in the preview panel
5. Your code will be executed and displayed in the preview window

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS (via CDN)
- Font Awesome Icons

## Project Structure

- `index.html` - Main HTML file containing the editor layout
- `style.css` - Custom styles for the editor
- `script.js` - JavaScript functionality for the editor

## Browser Compatibility

This code editor works best in modern browsers:
- Chrome (recommended)
- Firefox
- Safari
- Edge
